# СигмаЛаб-Кам (SigmaLab Cam)

Учебная программа кафедры телевидения и управления (ТУ) ТУСУР для лабораторной работы № 4
«Измерение и коррекция координатных искажений в телевизионном изображении программными средствами».
Заменяет используемые в работе AverTV6 (захват изображения), Imatest (модуль Distortion), ASRix (калибровка камеры
и выпрямление изображения) и файлы Mathcad (коэффициенты искажений, модель сферических искажений «Дисторсия»).

- Авторы лабораторной работы: Каменский А.В. (доцент кафедры ТУ), Курячий М.И. (профессор кафедры ТУ)
- Разработчик программы: Колесников И.Д.
- © 2026 ТУСУР, кафедра ТУ; учебная лицензия кафедры — `src/Resources/license.txt`

## Принцип

Как и СигмаЛаб, программа даёт **инструменты**, а не выполняет лабораторную работу: студент сам снимает таблицы,
выделяет рабочую зону, расставляет точки, переносит результаты в таблицы и строит графики — по методичке.
Команды названы так же, как в Imatest и ASRix (Pattern, Decentering calculation, Camera Management, Point List, Rectify…),
чтобы их легко было найти по тексту методички. Серий измерений «под пункты методички» нет.

## Состав

- Захват (AverTV): устройства DirectShow (плата видеоввода, USB-грабер, веб-камера, ТВ-тюнер), выбор формата и входа
  (кроссбар: композитный, S-Video), окна свойств драйвера, перекрестие и сетка для установки таблицы, снимок с усреднением
  кадров и автосохранением в папку.
- Distortion (Imatest): шахматное поле (squares) и сетка (grid) — автоматический поиск узлов с уточнением до долей пикселя,
  модели 3-го (k1, формула 1.4) и 5-го (h1, h2, формула 1.5) порядка, Decentering calculation, SMIA TV distortion,
  рисунки (distortion figure, radial plot, radius correction), исправленное изображение; коэффициенты (1.1)–(1.3) и
  K1–K4 по крайним линиям. Поворот таблицы (перспектива) учитывается и не искажает k1.
- Калибровка (ASRix): шаблон сетки 13×10 (ASR-grid), расстановка точек по порядку с лупой, привязкой и подсказкой следующей
  точки, Camera Management (k1, k2, центр дисторсии), Corrected Source Image, Save Corrected Image, Rectify с Output Parameters,
  Point List (F8).
- Коэффициенты (Mathcad): формулы (1.6)–(1.11), таблица 1.1 для исходного и выпрямленного изображений, калькуляторы (1.1)–(1.3).
- Модель сферических искажений (Mathcad «Дисторсия»): формулы (1.12), (1.13), прямой и обратный пересчёт координат,
  адаптивная линейная интерполяция (рис. 1.9), график ρ1(ρ).
- Дополнительно: инструмент «Точка» (расстояния, прогиб Δh), генератор тестовых таблиц (рис. 1.4, 1.5), имитация съёмки
  таблицы камерой (угол α, k1), график по таблице (табл. 3.1).

## Совместимость

Windows 7 SP1, 8.1, 10, 11 (32 и 64 бит). Написано на C# / WinForms под .NET Framework 3.5 с `App.config`, разрешающим
запуск на .NET 4.x: в Windows 7 есть 3.5, в Windows 10/11 — 4.8, поэтому ничего доустанавливать не нужно.
Захват — DirectShow (qedit.dll, входит в Windows). Интерфейс учитывает масштаб экрана 125–200%.

## Сборка

Нужен .NET SDK 8+ (на Linux или Windows). Установщик — Inno Setup 6 (на Linux через wine).

```sh
./build.sh          # Linux: тесты ядра, SigmaLabCam.exe, ../dist/*-portable.zip и ../dist/*-setup.exe
build.cmd           # Windows
```

Результат: `src/bin/Release/net35/SigmaLabCam.exe` (+ `SigmaLabCam.exe.config`, он обязателен рядом с exe).

Релиз собирает GitHub Actions (`.github/workflows/release.yml`): поднять `<Version>` в `src/SigmaLabCam.csproj`, закоммитить и
отправить тег той же версии — установщик и портативный архив появятся в файлах релиза.

```sh
git tag -a v1.0.1 -m "Что нового" && git push origin main v1.0.1
```

## Устройство

```
src/Core   обработка без UI: ImageData, ImageOps, Geometry (гомография, Левенберг — Марквардт), Lens (модель 1.4/1.5,
           подгонка «сетка + дисторсия»), GridDetect (поиск узлов шахматного поля и сетки), DistortionAnalysis,
           Calibration (шаблон сетки, профиль камеры, выпрямление), Coefficients (1.1)–(1.11), Warp (1.12, 1.13, рис. 1.9),
           TestCharts (таблицы и имитация съёмки)
src/IO     TIFF без сжатия, GDI+ для прочих форматов, Capture — захват DirectShow
src/UI     окна WinForms в цветах ТУСУР (#3C388D, #9ABF38)
tests      тесты ядра (.NET 8): восстановление k1/k2 по имитированным снимкам (в т. ч. при ±45°, шуме и чересстрочности),
           калибровка и выпрямление, формулы методички, модель сферы
installer  скрипт Inno Setup
tools      make_icon.py — значок программы
```

`SigmaLabCam.exe --shots <папка>` — служебный режим самопроверки интерфейса (снимки окон на синтетических данных).
